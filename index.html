TESS - Enterprise World Model

Temporal knowledge graph + LLM reasoning over an evolving organization

How the system works

1. SourcesSlack, email, calendar, meeting notes, documents
→
2. LLM ingestionMessy text becomes clean facts (who, what, when)
→
3. Temporal graphPeople, tasks, projects, documents, meetings. Every link has a start and end date
→
4. ReasoningPaths, impact, ownership and changes as of any date
→
5. LLM answersThe LLM gets graph facts as context instead of loose documents
